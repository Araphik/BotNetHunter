## 1 Общее описание системы

### Назначение

BotNetHunter - веб-приложение для анализа профилей и сообществ ВКонтакте на признаки ботоподобного поведения. Система предназначена для автоматизированной оценки риска того, что профиль или часть участников сообщества являются ботами, спам-аккаунтами или искусственно созданными учетными записями.

Приложение может использоваться для:

- проверки отдельных VK-профилей;
- анализа участников VK-сообществ;
- сохранения истории выполненных проверок;
- администрирования пользователей и лимитов;
- настройки весов и параметров аналитических модулей;
- просмотра базовых системных метрик.

### Описание системы

Система представляет собой серверное веб-приложение на FastAPI с HTML-интерфейсом на Jinja2. Пользователь взаимодействует с приложением через браузер: регистрируется, входит в личный кабинет, указывает ссылку, ID или короткое имя профиля/группы ВКонтакте и запускает анализ.

Для анализа используются данные VK API: сведения профиля, друзья, записи на стене и участники групп. Полученные данные обрабатываются несколькими аналитическими модулями:

- `profile_analyzer` - анализ базовых данных профиля;
- `social_graph_analyzer` - анализ социального графа и друзей;
- `behavior_analyzer` - анализ поведения и публикаций;
- `cross_check_analyzer` - кросс-проверка согласованности данных.

Результаты анализа сохраняются в SQLite-базу данных и доступны пользователю в истории проверок. Администратор имеет отдельную панель управления, где может просматривать статистику, управлять пользователями, менять лимиты и параметры анализаторов.

Подробное описание системы: [`docs/SYSTEM_SPECS`](docs/SYSTEM_SPECS)

## 2 Функциональное назначение

### Описание внешних функций (API)

Основное взаимодействие с системой выполняется через HTML-страницы и HTTP-маршруты FastAPI.

| Метод | Путь | Назначение |
| ----- | ---- | ---------- |
| `GET` | `/` | Страница входа |
| `POST` | `/login` | Авторизация пользователя или администратора |
| `GET` | `/register` | Страница регистрации |
| `POST` | `/register` | Регистрация нового пользователя |
| `GET` | `/logout` | Выход из системы |
| `GET` | `/dashboard` | Личный кабинет пользователя |
| `POST` | `/analyze` | Запуск анализа профиля или группы |
| `GET` | `/history/{history_id}` | Просмотр результата анализа |
| `POST` | `/account/delete` | Удаление аккаунта пользователя |
| `GET` | `/admin` | Главная страница панели администратора |
| `GET` | `/admin/users` | Управление пользователями |
| `POST` | `/admin/users/{user_id}/block` | Блокировка пользователя |
| `POST` | `/admin/users/{user_id}/unblock` | Разблокировка пользователя |
| `POST` | `/admin/users/{user_id}/limit` | Изменение лимита пользователя |
| `GET` | `/admin/weights` | Просмотр весов аналитических модулей |
| `POST` | `/admin/weights/save` | Сохранение весов аналитических модулей |
| `GET` | `/admin/weights/reset` | Сброс весов аналитических модулей |
| `GET` | `/admin/weights/parameters` | Настройка параметров модулей |
| `POST` | `/admin/weights/parameters/save` | Сохранение параметров модулей |
| `GET` | `/admin/metrics` | Просмотр метрик системы |

Для анализа профиля или группы используется маршрут `POST /analyze`. Он принимает данные формы:

| Поле | Описание |
| ---- | -------- |
| `target` | ID, короткое имя или ссылка на профиль/группу ВКонтакте |
| `target_type` | Тип цели: `user` для профиля или `group` для сообщества |

Подробное описание API: [`docs/api/README.md`](docs/api/README.md)

#### Описание ошибок

Ошибки в пользовательском интерфейсе отображаются на HTML-страницах в виде сообщений. Основные ситуации:

| Ситуация | Причина |
| -------- | ------- |
| Неверный email или пароль | Пользователь ввел неправильные учетные данные |
| Аккаунт заблокирован | Администратор заблокировал пользователя |
| Лимит исчерпан | Пользователь превысил дневной лимит анализов |
| VK токены не заданы | В `.env` отсутствует `VK_TOKEN_1` и другие токены |
| Не удалось получить данные профиля | Профиль не найден, закрыт или VK API вернул ошибку |
| Не удалось получить участников группы | Группа не найдена, закрыта или список участников недоступен |

Критичные ошибки конфигурации останавливают запуск приложения:

- не задан ни один VK API токен;
- не задан `SECRET_KEY`;
- не заданы `ADMIN_EMAIL` или `ADMIN_PASSWORD`.

Подробное описание ошибок: [`docs/api/README.md`](docs/api/README.md)

## 3 Алгоритм настройки и запуска

### Структура директорий репозитория

```text
project_docker/
├── analyzers/          # Модули анализа профиля, поведения, соцграфа и кросс-проверок

├── requirements.txt    # Python-зависимости
└── README.md           # Рабочая документация проекта
```

### Входные точки в программу

Основная входная точка приложения:

```text
app/main.py
```

FastAPI-приложение создается в переменной:

```python
app = FastAPI(title="BotNetHunter")
```

Команда запуска через Uvicorn:

```bash
uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```

В Docker-контейнере используется команда из `Dockerfile`:

```bash
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Дополнительные важные точки входа:

| Файл | Назначение |
| ---- | ---------- |
| [`api/endpoints.py`](api/endpoints.py) | Функции `analyze_user` и `analyze_group` |
| [`app/database.py`](app/database.py) | Подключение к базе данных |
| [`app/auth.py`](app/auth.py) | Авторизация и работа с токенами сессии |
| [`core/vk_client.py`](core/vk_client.py) | Клиент для обращения к VK API |
| [`core/token_manager.py`](core/token_manager.py) | Управление VK API токенами |
| [`config/settings.py`](config/settings.py) | Загрузка переменных окружения |
| [`config/weights.py`](config/weights.py) | Значения весов и параметров анализаторов |

### Алгоритмы запуска ПО для отладки

1. Перейти в директорию проекта:

```bash
cd project_docker
```

2. Создать виртуальное окружение:

```bash
python -m venv .venv
```

3. Активировать виртуальное окружение.

Для macOS/Linux:

```bash
source .venv/bin/activate
```

Для Windows:

```bash
.venv\Scripts\activate
```

4. Установить зависимости:

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

или:

```bash
make install
```

5. Создать файл `.env` в корне проекта:

```bash
touch .env
```

6. Заполнить обязательные переменные окружения:

```env
VK_TOKEN_1=your_vk_token
SECRET_KEY=replace_with_random_secret_key
ADMIN_EMAIL=admin@example.com
ADMIN_PASSWORD=admin_password
```

`SECRET_KEY` можно сгенерировать командой:

```bash
python -c "import secrets; print(secrets.token_hex(32))"
```

7. Проверить корректность импорта приложения:

```bash
make check
```

8. Запустить сервер разработки:

```bash
make run
```

или:

```bash
uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```

9. Открыть приложение:

```text
http://127.0.0.1:8000
```

## 4 Требования к аппаратному обеспечению

Минимальные требования для локального запуска:

| Компонент | Требование |
| --------- | ---------- |
| Процессор | 2 ядра |
| Оперативная память | 2 ГБ |
| Свободное место на диске | 1 ГБ |
| Сеть | доступ к интернету и VK API |

Рекомендуемые требования:

| Компонент | Требование |
| --------- | ---------- |
| Процессор | 4 ядра |
| Оперативная память | 4 ГБ и более |
| Свободное место на диске | 2 ГБ и более |
| Сеть | стабильное соединение с интернетом |

Ограничения производительности:

- скорость анализа зависит от доступности VK API;
- при анализе групп время выполнения растет пропорционально количеству участников;
- большое количество параллельных проверок может приводить к ограничениям VK API;
- SQLite подходит для учебного и небольшого локального развертывания, но для высоконагруженного использования лучше заменить хранилище на серверную СУБД.
